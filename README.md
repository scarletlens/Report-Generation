# 月度运行报告生成工具

这是一个本地 Web 工具，用于根据 `material` 文件夹内的报表数据、资源清单和报表模板，生成对应厅局、时间范围的 Word 月度运行报告。

## 一键启动

在项目根目录运行：

```sh
./start.sh
```

启动后终端会显示访问地址：

- 本机访问：`http://localhost:端口`
- 局域网访问：`http://本机IP:端口`

如果端口被占用，脚本会自动顺延到下一个可用端口。按 `Ctrl+C` 可停止服务。


说明：

- GitHub 仓库默认不会上传 `material` 下的真实数据文件。
- 仓库只保留 `material/`、`material/其他资源清单/`、`material/其他利用率/` 这三个空目录结构。
- 实际使用前，需要手动把源数据文件放入这些目录中。

## GitHub 上传说明

项目已通过 `.gitignore` 配置为：

- 上传代码和说明文档；
- 不上传 `material` 中的真实数据；
- 保留 `material` 目录及其子目录的空文件夹结构。

也就是说，推送到 GitHub 后，别人拉取到仓库时可以直接看到应该把哪些源数据放到哪里，但不会拿到你的真实业务数据。

## 首次使用前需要准备的文件

请在 `material` 目录下按下面结构提供源数据：

```text
material/
├── 报表模板.docx
├── 报表数据.xlsx
├── 资源清单.xls
├── 其他资源清单/
└── 其他利用率/
```

其中各文件和目录用途如下：

- `报表模板.docx`
  - Word 报表模板。
  - 程序会在此基础上生成最终报告。

- `报表数据.xlsx`
  - 基础业务数据文件。
  - 当前至少应包含：
    - `安全态势`
    - `地址段`
  - `利用率` 分页可选。如果没有，也不会影响程序启动。

- `资源清单.xls`
  - 主资源清单。
  - 用于建立 `IP -> 厅局 / 系统 / 资源属性` 的映射关系。

- `其他资源清单/`
  - 补充资源清单目录。
  - 用于存放主资源清单中没有覆盖到的资产清单。
  - 支持 `.xls`、`.xlsx`、`.xlsm`。

- `其他利用率/`
  - 补充利用率目录。
  - 用于存放额外的利用率文件。
  - 支持 `.csv`、`.xls`、`.xlsx`。

## 数据来源

### 报表数据.xlsx

当前主要读取以下分页：

- `安全态势`：用于生成安全态势内容。
- `地址段`：用于根据 IP 判断 `信创` 或 `非信创`。
- `利用率`：可选兜底分页。如果不存在，不会影响系统启动和查询。

### 资源清单

资源清单用于建立 IP 映射关系：

```text
IP -> 厅局名称、系统名称、服务类型、vCPU、内存、系统盘、数据盘、启用时间、停用时间
```

读取来源包括：

- `material/资源清单.xls`
- `material/其他资源清单/` 下的 `.xls`、`.xlsx`、`.xlsm`

如果某个资产不在主资源清单中，可以放到 `其他资源清单` 文件夹里，表头保持基本一致即可。

磁盘统计规则：

- `系统盘 = 系统盘 + 高性能系统盘`
- `数据盘 = 数据盘 + 高性能数据盘`

### 利用率文件

利用率数据可以放在：

- `material/` 根目录
- `material/其他利用率/`

支持文件类型：

- `.csv`
- `.xlsx`
- `.xls`

利用率文件名只用于识别年月，文件名中需要包含类似 `2026年4月` 的年月信息。文件名不用于识别厅局或系统。

示例：

```text
2026年4月利用率.csv
2026年4月广东省总工会.xlsx
2026年4月任意说明文字.xls
```

利用率文件内的列按以下顺序读取：

```text
uuid，ip，cpu 利用率，内存利用率，磁盘利用率
```

每条利用率数据会通过文件内的 IP 去资源清单和其他资源清单中查找对应的厅局和系统。找不到 IP 映射关系的数据不会进入报表。

推荐做法：

- 一个文件对应一个月份；
- 文件名中必须包含年月，例如 `2026年4月`；
- 文件名可以带任意补充说明，例如：
  - `2026年4月利用率.csv`
  - `2026年4月广东省总工会.xlsx`
  - `2026年4月补充数据.xls`

## 查询逻辑

### 厅局匹配

页面上的厅局支持模糊搜索。查询时也兼容名称包含关系，例如选择 `广东转型综合改革示范区` 时，可以匹配资源清单中的 `广东转型综合改革示范区管理委员会`。

### 利用率优先级

查询某个月时：

1. 优先读取外部利用率文件中该月份、该厅局匹配 IP 的数据。
2. 如果外部利用率文件中没有匹配数据，再回退到 `报表数据.xlsx` 的 `利用率` 分页。
3. 如果 `报表数据.xlsx` 没有 `利用率` 分页，则跳过兜底，不报错。

### 信创 / 非信创

`信创` 和 `非信创` 是全局过滤条件，不只影响安全态势。

所有带 IP 的内容都会通过 `地址段` 分页判断区域：

```text
IP -> 地址段 -> 信创 / 非信创
```

该规则会应用于：

- 云资源使用情况
- 云资源规模情况
- 安全态势

### 云资源规模情况

云资源规模情况来自资源清单和其他资源清单，只展示查询时间范围内发生变化的资源：

- 启用时间在查询范围内：`新增资源`
- 停用时间在查询范围内：`核减资源`
- 启用时间和停用时间都在查询范围内：`新增并核减`

如果资源一直存在，但启用时间和停用时间都不在查询范围内，不会显示在该部分。

### 安全态势

安全态势来自 `报表数据.xlsx` 的 `安全态势` 分页。

报表只体现以下字段：

- 受攻击 IP
- 攻击类型
- 受攻击系统
- 严重程度
- 数量

严重程度会参考攻击结果：

- 如果攻击结果为成功、失陷、入侵等，保留原严重程度。
- 如果攻击结果为尝试、失败、阻断、拦截等，高危会降为中危，中危会降为低危。

## 页面操作流程

1. 打开 Web 页面。
2. 搜索并选择厅局。
3. 选择月份，或切换为时间范围。
4. 勾选 `信创`、`非信创`，可单选也可都选。
5. 点击 `查询`，页面显示预览结果。
6. 确认数据后点击 `生成报表`。
7. 浏览器会下载生成的 Word 报表。

## 报表样式

生成的 Word 报表为 A4 竖版，包含：

- 浅色页面背景
- 淡色波纹底纹
- 居中页码
- 现代化表格样式
- 一级标题、小标题层级区分
- 表格内容按字段类型居中或左对齐

## 常见问题

### 页面提示“读取选项失败”

通常是数据文件结构异常或临时文件干扰。当前程序会自动跳过单个异常的资源清单或利用率文件，但仍建议检查：

- `material/报表数据.xlsx` 是否存在。
- `报表数据.xlsx` 是否包含 `地址段` 分页。
- 资源清单是否能正常打开。
- 利用率文件名是否包含 `xxxx年x月`。
- 是否存在 Excel 临时文件，如 `.~xxx.xlsx`。

### 查询不到利用率

优先检查：

- 利用率文件名是否包含查询月份，例如 `2026年4月`。
- 利用率文件内第二列是否为 IP。
- 该 IP 是否存在于 `资源清单.xls` 或 `其他资源清单/` 中。
- 该 IP 是否属于页面勾选的 `信创 / 非信创` 区域。

### 局域网无法访问

启动脚本默认监听 `0.0.0.0`，一般局域网可访问。若其他电脑无法访问，请检查：

- 是否使用终端显示的局域网访问地址。
- 两台电脑是否在同一局域网。
- 本机防火墙是否阻止 Python 或该端口。
- 公司网络策略是否限制局域网互访。
